# Trava

Track every street you've explored. Trava turns your walks into glowing city maps.

> **Private repository — not open source.**

---

## Tech Stack

- **Swift / SwiftUI** — iOS app, UI framework
- **CoreData** — offline-first local storage
- **CoreLocation / MapKit** — GPS tracking and map rendering
- **Firebase Auth** — Sign in with Apple, Google, email
- **Firebase Firestore** — cloud sync and backup
- **HealthKit** — import workout routes from Apple Health
- **OpenStreetMap (Nominatim)** — city boundary polygon data
